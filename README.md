# Student Performance Prediction Using Machine Learning

## Project Overview
This project predicts student performance using Machine Learning.

## Objectives
- Analyze student academic data.
- Perform data preprocessing.
- Develop a Machine Learning model.
- Predict student performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Streamlit

## Dataset
The project contains 800 synthetic student records.

## Machine Learning Algorithm
Random Forest Classifier.

## Applications
- Flask Web Application
- Streamlit Application

## Project Modules
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Training
5. Model Evaluation
6. Performance Prediction

## Note
This is an educational project using synthetic data.
Predictions should not be used for real student grading.
